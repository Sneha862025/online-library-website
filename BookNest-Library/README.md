# BookNest Library
Pinterest-inspired online library built with only HTML5 and CSS3 (no JavaScript).

## Run
Open `index.html` in a browser. Internet is needed for fonts and sample images.

## Pages
index, books, categories, book-details, about, contact, login, register. All share `css/style.css`.

## Customize
Sample images load from picsum.photos. Replace any `src` with your own files from `images/`.
